# 浏览器验收

进程内 DOM 检查不能证明布局、原生 dialog、指针／触屏、真实存储与下载行为。本页记录可复现任务，用于允许浏览器操作的环境；宿主限制某条通道时不换通道绕过。未实际执行的条目保持未验证。

使用最终交付的 HTML，记录浏览器／版本、屏幕宽度和每项结果。不要用旧版本截图证明新字节通过。

| 任务 | 验收结果 |
| --- | --- |
| 桌面首次打开 | 左侧居中总流程，中间和右侧点击提示，无重复章节条 |
| 中文／English 切换 | 文案、状态与无障碍标签同步；当前路线、展开、滚动、对话阅读和续聊目标保留；原文与附件不变 |
| 英文／中文示例首次打开与重新打开 | 对应默认语言正确；手动选择可保存；深链语言优先；存储禁用时仍可切换 |
| 总图→子流程→节点 | 左总图保持，章节标题正确；真实分叉／汇合清晰，选中仅高亮上游路径，右侧摘要和文件易读 |
| 图标、文件卡与更多工具 | 类型与状态不混淆，简短用途与真实文件名可读，所有原操作仍可访问 |
| 拖动两条分隔线；用键盘 Home/End/方向键 | 栏宽约束可读，选择／展开／滚动不丢失 |
| 展开记录→打开 Markdown→返回 | 排版可读，原展开状态与滚动恢复 |
| 点击轮次卡片；关闭／Escape／前进返回 | 页内独立问答框，键盘焦点与索引范围恢复 |
| 普通无 UUID 对话 | 两轮问题／回答分组，本地标识与原始编号区别可见 |
| 有效关联与失效旧关联一起载入 | 有效项可用，待恢复项可查看和导出 |
| 搜索助手回复／附件正文 | 命中打开正确内容，不混入无关节点 |
| 下载 Markdown／附件／续聊包 | 原字节或所选交接范围正确，无额外代码正文 |
| 审查旧版本，导出批准或拒绝 | 差异可读，未批准不应用，关闭回到工作台 |
| 390px 窄屏与触屏 | 明确视图切换、可点击控件、正文无裁切 |
| 深色与减少动态效果 | 对比、文字层级、状态文字可辨，功能保持 |

更新服务另验：未授权仅查看版本说明；授权后下载；开启页面内检查才提示新版本，隐藏页面暂停；令牌不进入 URL 或本地持久存储。无结账页，不发起付款。

可观察新手任务：找到“本阶段做了什么”；找到一个文件并说明其用途；定位该阶段的一轮问答；把当前状态交给另一个 AI；识别一次版本修改。记录完成时间、误点位置和不理解的词，不因测试者熟悉项目而替读者推断。
