# 总流程与子流程

Pro 0.4.0 桌面首次打开即显示三栏：左侧为水平居中的项目总框线图，中间提示“点击左侧流程框，查看阶段流程”，右侧提示“选择流程中的节点，查看说明与文件”。点击左侧阶段后，中间显示子流程；再点击子流程节点，右侧显示简短说明与文件。明确的节点／文件深链接可直接进入详情。总图和子图均为矩形与箭头，不使用 Git 点线导航。

复用固定模板，通过项目数据适配内容。桌面并排，手机使用总览、流程、详情入口切换，不上下堆叠两张完整页面。删除重复的章节条、章节选择器和节点选择器；阶段跳转通过图内节点完成。

先应用实际栏宽再绘图，总览滚动条使用两侧对称留白；适应栏宽时为图形保留相等边距，不造成额外横向溢出。纵向仍从流程顶部开始阅读。

两条分隔线支持指针拖动与键盘方向键、Home/End 调宽，并保留三栏最小可读宽度。比例可存入 localStorage；存储不可用时正常运行。窗口尺寸变化时约束栏宽，调宽不添加导航历史，也不重建正在阅读的内容。切换到窄屏保留当前文件与阅读位置。

## 总图入口

`navigation.source_chapter` 指定总览记录，总图保留该章全部节点与关系。`navigation.items` 将总图节点映射到子流程：

```json
{"id":"scope","source_node":"scope","chapter":"foundation","node":"setup","label":"需求定义","order":0}
```

`source_node` 缺省使用入口 ID。`navigation.edges` 继续引用总览记录中的 from、to、type；不允许遗漏所选事件间的已有关系。状态与证据从原记录读取，入口不能改写状态。order 为唯一非负整数，边指向后续事件。旧 lane 字段仅兼容保留，不控制新布局。

缺少 navigation 时，第一章作为总图，其节点打开本章详情，不自动推断章节间依赖。start 只作为不完整深链接的后备目标；无 hash 始终先显示总图。

## 紧凑布局

原 Archify 图仍须经过拓扑与连线检查。打包器优先寻找窄纵向布局：连续步骤直接向下，分叉和汇合通过框外通道连接。可以按拓扑调整事件位置，不能更改日期或因果。完整保留每条边，再检查交叉、重叠与穿框；窄布局无法通过时，保留原已验证布局，不能删边换取紧凑。

默认适应栏宽，正常滚轮和触屏手势用于纵向阅读；通过按钮或 Ctrl／Command 加滚轮缩放。不要将全部节点压缩成不可读的缩略图。进入子流程先展示流程起点；原 Archify 图保留下载入口。

## 简明说明与文件

框内显示标题、类型、状态及资源数。右侧默认只显示标题、小状态标签、关键摘要、必要限制与相关文件。**不显示连接关系列表。** 日期、分支、类型、来源、原始说明和文件注释统一收进默认关闭的“查看详细记录”。阶段信息末尾提供矩形“打开对话索引”按钮，不再重复展示对话摘要或复制阶段定位。标题、正文和辅助信息区分字号与字重。状态标签保留文字；已验证绿色、已完成蓝色、进行中黄色、待确认／暂停／被替代灰色，不能把完成等同于验证。首屏空态隐藏尚不可用的缩放与阅读操作。

在 manifest 的 chapter 中可增加展示字段，不覆盖原始事实记录：

```json
{
  "id":"foundation",
  "label":"基础版本",
  "record":"foundation/evolution.json",
  "viewer":"archify-foundation.html",
  "presentation":{
    "setup":{"title":"搭建工程与测试","summary":"建立运行环境、页面基础和自动化测试。","reason":""}
  },
  "change_groups":{
    "setup":[{"title":"工程与测试基础","summary":"配置项目依赖和基础测试。","artifact_indices":[0,1]}]
  }
}
```

presentation 只允许字符串 title、summary、reason；标题不能空。摘要通常一两句，避免术语堆积。空 reason 隐藏默认原因段落；必须保留提案、失败、延期、仅本地验证等实质限定，不能把计划写成实现。原文保留在详细记录，搜索覆盖两种文案。

多个代码文件按功能归组，不逐个展开代码差异。artifact_indices 对应原 artifacts 的零起始索引，不能重复或越界；未分组资源仍保留。默认最多展示三个文件卡片，其余放在“其余 N 个文件”中，不删除记录。卡片首行是用途超链接，次行是真实文件名；长文件名省略显示并保留完整 title。普通点击页内阅读，Ctrl／Command 点击打开快照，另有紧凑下载入口。文件正文、Markdown 原文、定位等完整阅读操作在打开文件后显示。不能凭文件名编造未读取的实现细节。

节点的“查看详细记录”、文件说明、依据与其余文件各有稳定的展开状态键。打开文件后经返回或面包屑回到节点，先恢复原有展开／折叠状态，再恢复滚动位置；不同节点与文件的状态不能串用。

## 对话索引与标题

索引在右栏显示轮次卡片，不自动展开第一条。点击卡片，在当前页面通过原生 `<dialog>` 打开独立的大阅读框；问题、回答与保存摘要按角色分组，正文默认渲染 Markdown，不编造缺失消息。桌面宽度最大 980px，窄屏接近全屏；标题与关闭按钮固定，正文独立滚动。搜索直达与深链接使用同一阅读框。关闭或 Escape 返回打开前的索引／上下文，恢复筛选、来源范围和列表位置；连续切换相邻摘录后也能关闭。浏览器前进／返回恢复对话正文的阅读位置，切换新轮次从开头显示。技术定位保留在折叠详情中，不另开浏览器窗口。

从阶段进入时显示原始 ID、真实行号／明确消息位置与手动关联的整轮摘录，并分别标注定位类型；这些均无时，才显示同来源任务候选；同来源不等于精确属于该阶段。没有关联时显示空态，明确点击“全部已收录对话”后才扩大范围。不能按标题、日期或相邻位置猜造关联。

标题只用于展示：优先使用同一原始轮次中用户新增的问题，清理 My request 等包裹文字、Markdown 标记并截取首句；保留实际文件标识中的下划线。只有摘要时标记“保存摘要”，只有助手回复时标记“已记录结果”。像“继续”这样的短问题可附同轮助手首句预览。用户问题缺失时不编造问题，不把来源说明当标题。整个过程使用本地规则，无额外模型请求；原文、source_title 和技术定位不变。搜索只命中助手回复时，仍使用完整原始轮次的用户问题作标题。

## 对话与模块双向关联

模块“查看详细记录”提供“关联已有对话”：保留明确的章节／节点目标后，显示全部已保存轮次供选择。点击“关联此对话”回到该模块索引；“退出关联选择”恢复模块范围。没有原始摘录时不自动扩大范围或生成问答。

对话阅读框的“关联模块”汇总同轮全部已保存消息的精确关联与手动关联，去重后可直接查看模块；手动项可移除，原记录项只读。同来源候选单独折叠，不计入确认关联。全局索引进入的对话提供现有模块选择器，同一轮可连续关联多个模块。改变关联立即刷新索引／阅读框，保留阅读位置；浏览器返回重新计算模块范围，不恢复过时的静态关联列表。

手动关联存为独立覆盖层，不修改嵌入的节点、消息或附件。可用时保存在项目隔离的 localStorage；失败时仅保留本次会话并明确提示，仍可导出。换浏览器或 HTML 文件前先“导出关联”，新版再“导入关联”；本地文件的浏览器存储范围不保证跨文件共享。

JSON 使用 `schema: chat-archify-manual-conversation-links`、`version: 1`、`project_id` 及 `links: [{chapter_id,node_id,group_id}]`，仅传递人工关联元数据。导入校验项目、格式和模块／轮次标识，使用已有唯一迁移映射并合并去重。严格导入拒绝未知项；恢复流程另行保留待恢复项，不将它们当作已确认关联。启动恢复有效项与失效项分开，一条失效不隐藏其余记录；未知项与损坏原文可备份，恢复之前不静默覆盖原 JSON。浏览器不允许存储与数据失效分别提示。文件不超过 1,000,000 字节，文本不超过 1,000,000 字符，最多 5,000 条关联。它不导入原始聊天或文件。首次生成 manifest 时设置稳定 `project_id`，更新保留该值；旧 manifest 使用标题和首项来源定位作为后备标识，改名／更换来源可能不兼容。

## 验证

运行资料、快照和工作台回归；对真实交付运行：

```sh
node tests/interactive-navigation.cjs "<packaged.html>" --all-data
```

检查首次三栏与两个空态、总图进入子流程、左侧总图保留、两条分隔线的指针和键盘操作、存储失败降级、调宽与跨断点保留阅读内容，以及对话关联的选择／退出、多模块与反向导航、本地保存／失败提示、元数据导入导出和原数据不变、全部节点与文件、展开／折叠状态恢复、对话框关闭／Escape／前进返回、返回层级、搜索与 Markdown。该工具是进程内 DOM 模型，不替代浏览器排版与操作验收。宿主允许时另做浏览器验证；受限时说明缺口，不绕过限制。
