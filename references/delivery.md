# 页面生成规范

## 生成与交付

读取 [references/graph-format.md](graph-format.md)，写 `evolution.json`。它是可迁移的事实记录；渲染器不读取聊天，也不替模型提炼事件。

默认交付完整的交互附件 HTML，并按 [交互图与附件工作流](interactive.md) 使用另行安装的 Archify 检查连线、生成框图并打包节点证据和文件快照。按 [章节工作台](workbench.md) 复用总览到子流程的固定 UI：桌面首次即显示三栏：左侧为水平居中的项目总框线图，纵向从顶部开始；中间与右侧为点击提示；点击左侧阶段显示中间子流程，再点子流程节点显示右侧说明和文件。两条分隔线可拖动调宽并保存偏好。复用浅色点阵画布、统一线性图标、细分隔线与靛蓝选中态；仅高亮真实上游路径。总图保持紧凑纵向，子图中可验证的分叉／汇合使用双列，复杂关系保留无交叉后备布局。不得为贴合效果图删并节点或补造关系。详情不显示连接关系列表；详细依据折叠保留。手机使用明确入口切换视图。项目差异通过 manifest 和记录数据配置，不重写模板。没有 Archify 时，说明缺少的依赖；只有在完整流程无法运行时才用 `render.py` 生成基础查看器，并明确它不等同于完整附件版。不能把 `file://` 链接作为获取产物的唯一方式。

默认交付到用户指定目录，或当前工作目录下的 `outputs/chat-archify/`（遵守宿主输出约定）：

- 交互 HTML：桌面首次左侧显示总框线图，中间与右侧保留空态提示；点击总图进入中间子流程，再点击节点／键盘激活联动右栏。分隔条支持拖动、方向键与 Home/End；调宽保留选择与阅读位置。本地存储不可用时仍可使用。移除重复章节条、章节选择器和节点选择器。窄屏使用总览／图／详情切换，不上下堆叠两个完整页面。右侧默认只展示标题、状态、关键摘要、必要限制和文件。文件链接以用途为主，真实文件名为次行；先显示最多三项，其余可展开。多个代码文件按功能归组，不逐文件展开全部差异。文件卡可显示已有用途注释的简短片段，完整注释仍保留。日期、分支、来源和原始说明收进一个默认关闭的“查看详细记录”；“打开对话索引”矩形按钮位于其下方，可直接访问。展开／折叠状态与阅读位置通过面包屑和浏览器前进／返回恢复；切换主题保留模式和框图状态。统一搜索覆盖阶段、文件正文和已保存对话摘录，显示类型与命中上下文；文件命中直达正文行，对话命中正文高亮。Markdown 默认渲染并保留原文及目录，多个行号定位作用于排版和原文。文件关联依据证据／产物数据计算；进入路径单独标明，不冒称来源关系。不重复展示对话摘要和复制阶段定位；技术信息中的“关联已有对话”入口继续保留。标题、说明与辅助信息区分字号和字重；状态标签保留文字并使用语义配色，已验证为绿色、待确认等为灰色，已完成不等于已验证。索引先显示卡片，点击后在当前页面打开独立的大阅读框，按用户、助手、保存摘要区分已收录消息；关闭或 Escape 回到原索引／上下文，保留筛选、列表位置和文件说明的展开状态，不新开窗口。按已记录的同任务、同轮次分组；卡片标题优先本轮用户问题，使用本地清理和截句，不调用模型，摘要仍标“保存摘要”。短问题可附同轮回复预览，原任务标题及定位保留在详细记录。阶段入口默认只显示精确或手动关联；任务 ID 本身不足以精确匹配。无关联时显示空态及已有来源资料；同来源候选与全部对话均由用户主动打开。同轮多模块优先预览并定位阶段匹配消息；进入／退出关联选择清除旧筛选，面包屑返回恢复原范围与筛选。提供同来源邻接摘录，清楚说明收录范围。只有来源记录包含已验证 HTTPS `original_url` 时才提供原任务入口，否则提供标题和任务 ID 供人工查找。已有 artifact.note 在详细记录或打开文件后可读；阶段时间与文件快照时间分别标注，未知时间显示未记录，不推断日期。技术 ID 默认收起。
- `evolution.html`：没有 Archify 时的轻量后备查看器。其本地链接受浏览器限制，交付时明确说明，不把复制路径等同于可直接下载。
- `evolution.svg`：矢量框图，与 HTML 放在同目录时可点击跳转到节点详情。
- `evolution.json`：稳定 ID 的结构化记录，供增量更新。
- `evolution.md`：可读的事件、来源及链接索引，无脚本也可阅读。

默认完整附件版：先按 [交互图与附件工作流](interactive.md) 准备来源、workflow、通过检查的 Archify viewer 和 manifest；然后打包（`<skill-dir>` 为本 skill 目录）：

```text
python "<skill-dir>/scripts/package_interactive.py" "<output-dir>/manifest.json" "<output-dir>/chat-archify.html"
```

随包虚构示例可用 `scripts/build_interactive_demo.py --archify-dir "<archify-skill-dir>" --out-dir "<output-dir>"` 一键重现；这只构建演示，不会替代对真实来源的提炼。基础渲染器仅依赖 Python 3.9+ 标准库；完整默认流程还需要 Node.js 18+ 和单独安装的 Archify。完整附件 HTML 无 CDN 或联网请求。

明确降级到基础查看器时才执行：

```text
python "<skill-dir>/scripts/render.py" "<output-dir>/evolution.json" --out-dir "<output-dir>"
```

该基础命令不生成 Archify 框图、完整文件阅读面板、跨类型全文搜索或对话轮次索引；不能描述为与完整附件版相同。缺少完整流程依赖时说明差异及缺失项。

标题保持简洁，长内容放详情。默认中文界面，可按用户需求调整模板文案。超过约 30 个重要节点时，合并琐碎事件或生成总览与独立子图并互相链接，不静默丢弃事件。没有 Python 时保留 JSON/Markdown，直接生成带来源说明的 Mermaid 图作为降级交付，说明未生成交互 HTML。
