# 交互图与附件

用户要的是能追溯事件并获取产物的页面。SVG 在某些应用里只作为图片显示，即使含链接也不能点击；本地路径链接也可能被浏览器拒绝。默认把交互 HTML 作为入口，保留 SVG 供图形导出。

## 生成可检查的图

1. 保留 `evolution.json` 的节点 ID、全部关系及证据。原始资料依旧是事实来源。
2. 如有 Archify，读取其 SKILL.md，使用 workflow schema v2，为总览和主题子图分别写规格。每张图最多约12个主要节点，使用主线、泳道和简洁标签；完整标题与说明保存在记录内。不能为消除交叉而悄悄删除有意义的关系。
3. 先用自动连线，再根据实际诊断调整所指的连线或布局。每张图运行 `validate ... --quality showcase --json` 和最终 `deliver`，检查全部9项。另运行 `python scripts/check_routes.py <viewer.html>` 检查实际 SVG 的全部连线对，包括共享节点的边；Archify 2.17 的9项通过仍可能漏掉这类交叉与重合。不能凭回执直接宣布零交叉。该补充检查支持正交 M/L 路径，不支持的路径会报错，不会静默略过。
4. 优先在规格里修正几何。如果需要修正生成后的路径，保留原版HTML及其精确回执，将修正版另存并记录自己的哈希与检查结果。旧回执不能覆盖修正后的字节；同时修改路径、几何元数据与标签位置，检查标签不遮挡其他连线。附件页面使用最终通过补充检查的版本。

Windows 若 CLI 使用系统临时目录时遇到 `realpath` 权限错误，可为当前命令指定任务目录内的 `TEMP`/`TMP`。不要修改全局环境，也不要改变浏览器安全限制。

## 打包节点详情与可用附件

Archify workflow schema 没有任意文件附件字段。不要把文件URL塞进 tag 或 sublabel 假装支持。准备一个 manifest，让记录与检查通过的图通过同一节点 ID 关联：

```json
{
  "title": "项目演进",
  "chapters": [
    {
      "id": "overview",
      "label": "项目总览",
      "record": "evolution.json",
      "viewer": "archify-overview.html"
    }
  ]
}
```

字段路径相对于 manifest；chapter ID 需唯一。`record` 是原来的 `evolution.json`，`viewer` 是最终已检查的HTML。图中与记录中的节点集合必须一致。

```text
python "<skill-dir>/scripts/package_interactive.py" "<output-dir>/manifest.json" "<output-dir>/project-interactive.html"
```

打包器先做全边对检查，再保留输入viewer的字节与 SHA-256，在新页面的 iframe 中加载。节点桥接使用 `data-node-id` / `aria-pressed` 和当前版本的 `Archify.focus.set`；属于本技能的集成实现，不是 Archify 承诺的公开API。点击在捕获阶段处理，以免原生切换选择时清空资源。升级 Archify 后要重测；若联动不可用，页面显示提示，仍可用“定位阶段”访问全部详情。

附件处理：

- 点击节点立即打开资源弹窗，资源列表排在叙述前，不能藏在窄屏下方或可收起的侧栏。重复点击同一节点也要打开；键盘 Enter/Space 同样处理。
- 文件名称使用真实 `<a href>` 链接。文本、代码、HTML和SVG链接通过 `text/plain` Blob 展示；常见位图按图片类型打开。另提供页内预览、下载与复制原始路径。Blob是本次页面会话的快照链接，不是永久分享地址。
- 文档与代码用 `textContent` 预览，不执行文档内HTML或脚本；图片在弹窗中查看。
- 本地文件内容嵌入交互HTML，下载通过内存 Blob 完成，不依赖 `file://`、本地服务器或其他服务。
- 文件显示为本次读取的快照；保留原始路径和内容 SHA-256，不能把快照称为实时文件。
- 已登记子图链接转为页面内章节切换；远程网址保留原链接并按实际状态标注，不自动请求。
- 目录提供清楚标记的目录索引，不假称已打包目录内容。单文件超过25 MB、凭据类文件或检测到明显密钥内容时仅保留位置和原因，不静默遗漏。
- 页面 CSP 阻止内容联网；Archify 的可选外部字体会使用系统字体降级。外部网页链接仍由用户点击打开。

只打包用户指定项目范围内、已获准读取的产物，不扫描额外私人目录。不要把完整敏感对话导出混入附件；仍采用经过范围审查的证据摘录。

## 验收与交付

校验所有节点、边、章节链接、来源和文件引用。逐项核对嵌入文件解码后的 SHA-256 与原文件；viewer 解码后的字节应与对应版本的回执一致。检查脚本语法、安全文本呈现及预览/下载逻辑。

浏览器允许时，检查节点联动、重复点击同一节点、资源链接、章节切换、搜索、图片/文本预览及下载，检查宽屏和窄屏。环境明确禁止某浏览器URL后，不用其他浏览器、CDP、本地服务等手段绕过；继续独立的结构、布局与文件检查并如实报告浏览器验证尚未完成。DOM模型测试只能作为代码逻辑证据，不能替代真实浏览器点击。

交付链接优先指向最终自包含 HTML；如用户需要，附离线ZIP（HTML及简短阅读说明），不再把静态SVG作为主要操作入口。更新已安装技能时保留显式调用策略。
