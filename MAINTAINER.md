# Pro maintenance / Pro 维护

This private repository includes the installable Pro skill at its root and the separately operated update service in `paid-updates/`. The release ZIP contains only the skill. See [the service guide](paid-updates/README.md) for manual licensing and authorized updates.

本私有仓库根目录为 Pro Skill，`paid-updates/` 为单独运行的授权更新服务。Release ZIP 只包含 Skill；部署服务另按[服务说明](paid-updates/README.md)操作。授权数据库、密钥、真实用户聊天和 Humanity Game 文件不属于发布内容。

Checkout is not connected. The service is not deployed by uploading this repository. Existing downloaded skills and offline HTML remain usable without the service.
